# Multi-App AI Agent Hackathon — FinAgent

**Hackathon:** Multi-App AI Agent Hackathon, Lemma × Comma Capital  
**Date:** 13 September 2026  
**Brief:** Build one useful, multi-step AI agent. Connect it to at least three external apps. Show how you know it works.

**Prize pool:** $15,000

This folder documents the hackathon-scope extension of FinAgent.

## Quick summary

We turn FinAgent from a read-only analyst into a closed-loop agent that delivers, solicits decisions, and records them.

**Three external apps integrated:**
1. **Telegram** — delivery + human-in-the-loop approvals
2. **Google Sheets** — audit trail / track record
3. **Google Calendar** — proactive event scheduling from company fundamentals

**Why this matters for FinAgent:** the morning note pipeline already analyzes; the hackathon extension closes the workflow: Analyze → Deliver → Decide → Record → Evaluate.
