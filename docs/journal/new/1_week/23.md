## Decisions made

- **Port 5434** — Changed from 5432 to avoid Windows PostgreSQL service conflict. Requires updating `DATABASE_URL`/`MIGRATION_DATABASE_URL` in `.env`.
- **POSTGRES_HOST_AUTH_METHOD=trust** — Enables passwordless local connections inside container for healthchecks/init scripts. External connections from host still use password auth.
- **RLS policy pattern** — Uses `current_setting('app.manager_id', true)::int` matching existing tables (recommendations, portfolios, etc.). API layer must `SET LOCAL app.manager_id` before queries.
- **Strong password** — Generated 32-char URL-safe token (`4B468yUsD08bSuXP6OLdoj0cGjhLvIzVosUCVO1qe6s`). Stored in `.env` (gitignored) and docker-compose default fallback.
- **Table name: `feedbacks` (plural)** — Matches existing pattern (`morning_notes`, `recommendations`). ADR-011 specified singular but codebase convention is plural.

## Decisions worth flagging

- **API endpoint for feedback not implemented** — Issue #94 will add `POST /morning-notes/{id}/feedback` endpoint.
- **Frontend integration deferred** — FeedbackModal and useFeedback hook to be built in Phase 2.
- **Feedback analytics fields deferred** — `confidence_delta`, `tags`, `original_*` snapshots to be added in Phase 3 per ADR-011.
- **Windows PostgreSQL service** — Local installation conflicts with Docker on port 5432. Kept disabled; use Docker for all local development.
- **Docker Compose default password** — Restored `${POSTGRES_PASSWORD:-...}` pattern to prevent future regressions.
