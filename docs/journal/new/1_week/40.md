## Concepts banked today

- Patch inputs/seams the unit consumes, never outputs the unit produces.
- Async-ness is created at definition time (`async def`), not at use time (`await`/`async with`) — got it wrong live with a `lambda: None` patch; `TypeError: NoneType can't be awaited`. Tutor had endorsed the lambda; tutor was wrong; logged.
- `=` vs `:` in parameter lists: default value (runtime binding, the class object itself!) vs annotation (metadata). Fixtures instantiate; defaults don't. A method called via the class is a plain function missing `self`.
- Fixture audit = same method as fake audit: walk the executed path, provide exactly the touched attributes (test ③ dropped Message/Chat/datetime — a tripwire, not decoration).
- Per-update exception granularity: `except Exception` swallows operational failures; BaseException signals (CancelledError, KeyboardInterrupt) pass through. Same lesson as journal 39, transferred to the resume path.
- Assert function *outputs*, not inputs: `decision_key("run-42", 7) in deleted_keys` via the real import; I asserted the tuple `("run-42", 7)` first — inputs where outputs live. Also: debug `print` diagnosed the shape, then left with the bug.
- Fakes: Option B — behavior scoped to the test that needs it (`fake_graph.ainvoke = failing_ainvoke` instance-level), class stays minimal.
