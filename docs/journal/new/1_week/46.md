## Decisions made

- **Epic split into 7 trackable issues** — Instead of one massive PR, each sub-issue is reviewable, testable, and has its own journal entry
- **Incremental test migration (ADR-038)** — Adapter wrapper pattern lets us migrate 75 call sites in 7 batches without breaking CI
- **LangGraph `map` pattern for fan-out (ADR-032)** — Dynamic, clean, works with v1.2.11; avoids static graph limits
- **Hybrid approval (ADR-033)** — Per-ticker + bulk + explicit Submit button; single LangGraph interrupt
- **Consolidate node (ADR-031)** — Portfolio-level risk in Python (deterministic, no LLM cost); future PortfolioRiskAgent can be added
