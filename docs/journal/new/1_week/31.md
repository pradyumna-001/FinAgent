## Decisions made

- **CORS origins come from env, not hardcoded** — `CORS_ALLOW_ORIGINS` JSON array, prod sets its own; dev defaults to the two Vite origins. No `["*"]` with credentials.
- **CORS tests are DB-free** — isolated `FastAPI()` + middleware only, per the issue's AC. Real-DB app boot on Windows hits intermittent asyncpg/Proactor `WinError 64`, so proving middleware behavior against a minimal app beats fighting the environment.
- **`allow_headers` explicit, not `["*"]`** — header-`*` is technically legal with credentials, but an explicit allow-list is auditable and documents exactly what the frontend sends.
- **`/health` shares the policy** — no special origin exception.
