- **English-only prompts; Portuguese reserved for the eventual end-user output.** Rule pinned: "we will only use Portuguese when the consumer is the actual user." RiskAgent's consumer is EditorAgent (a machine), so prompts are English. Diverges from #77 verbatim Portuguese prompt.
- **Separate parse chunk from agent chunk (option B).** `parse_risk_json` is pure and unit-testable without mocking the LLM. Chunks: 1 = prompt, 2 = agent skeleton, 3 = parser, 4 = wire-in + tests. Vs. option A (fold parse into one fat chunk) which would have broken the ≤25-line chunk rule and made the parser untestable in isolation.
- **Parser drops malformed items, keeps the rest, returns `(flags, dropped_count)`.** Single-source-of-truth rule (`get_args` from the `Literal`, set comprehension from `Severity` enum) means schema changes propagate automatically.
- **Parser does not raise.** Best-effort return; drop accounting + structured `logger.warning` for the operator; the agent decides whether to escalate to a `DataFlag` based on `dropped_count`.
