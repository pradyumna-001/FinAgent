## Decisions made

- **Patch over DI for poller collaborators** — DI of the saver re-enters the CM-ownership trap; patching leaves construction inside the coroutine lifetime.
- **Option B for cancellation**: `except asyncio.CancelledError` (log, swallow) + `finally: redis.aclose()`, then the pre-existing INFO return becomes reachable. Constraint added: if the poller is ever wrapped in `wait_for`/timeout, re-raise — swallowing breaks supervisor contracts.
- **Redis patch target is `redis.asyncio.Redis`, not the poller module** — line 27 imports *inside* the function at call time; the poller module namespace never holds the name. "Where to patch" = where the lookup happens *when it happens*.
- **Fake's `get_updates` returns the update once, then raises `CancelledError`** — doubles as loop-exit lever AND regression guard for Option B (assert the returned flag message).
- **Real `encode_callback` in the fake's `data`** — round-trips with `decode_callback`; pasting a literal string would test nothing about the wire format.
- **Mocks sized to the call path, no more** — test ① touches zero collaborators and therefore needs zero fakes. Mocking more hides that the path is cheap.
