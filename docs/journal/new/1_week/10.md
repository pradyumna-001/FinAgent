## Decisions made

- **Header naming** – Kept `manager‑id` on the wire to match the DB column name; translation to Portuguese is a docs‑only task.
- **Belt‑and‑suspenders** – Retained both the `int()` cast and the quoted f‑string; they protect against non‑numeric payloads and provide a final safety net if `int()` were ever removed.
- **RLS backup** – Left the `WHERE manager_id = :mid` clause as a safeguard for any RLS failure scenario (role escalation, policy disable, GUC missing).
- **Engine monkey‑patch** – Chose fixture‑level monkey‑patching because `importlib.reload` would leave stale references in modules that imported `engine` at import time.
- **Scope discipline** – Skipped the `alembic/env.py` and `tests/conftest.py` changes that depend on the yet‑unmerged `MIGRATION_DATABASE_URL`. Including them would break the migration test harness and violate the principle that a PR must be self‑contained.
- **Journal correction** – Briefly noted that the earlier journal entry (#09) incorrectly claimed #04a’s work was lost; the files actually survived the flatten, while #04b’s files were truly missing.

## Decisions worth flagging

- **Bound‑engine fixture** – Demonstrates a pattern for testing code that uses a singleton async engine created at import time.
