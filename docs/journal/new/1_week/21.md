## Decisions made

- **Async checkpointer factory** — `create_graph()` uses `AsyncPostgresSaver` inside async context; `dev_graph` uses `InMemorySaver` at module level. Matches LangGraph docs pattern for production async usage.
- **Partial returns + reducers** — Only way to support parallel agent execution with shared keys (`data_freshness`, `flags`). Agents return only what they modify; LangGraph merges via reducers.
- **Severity enum in RiskFlag** — `parse_risk_json` now returns `Severity` enum not string. Aligns with `RiskFlag` TypedDict definition.
- **LangSmith tags at invoke time** — Passed in `config` dict, not graph construction. Allows per-run dynamic values.
- **InMemorySaver for local dev** — PostgresSaver works but requires Docker networking setup; `dev_graph` unblocks iteration.

## Decisions worth flagging

- **PostgresSaver local setup** — Windows Docker gateway IP issues with pg_hba.conf `trust` auth. Not a code problem; production (RDS) uses standard auth. Defer local Postgres debugging.
- **Partial returns require test helpers** — Integration tests must manually merge returns (see `merge_result` in `test_agents.py`). This is the reducer contract.
- **No fallback Nemotron in EditorAgent** — Returns `None` on infra error → `DataFlag(FATAL)`. Acceptable for now; monitor rate limits.
- **Confidence penalty post-parse** — Applied after LLM response via `apply_confidence_penalties()`. More deterministic/testable, but LLM doesn't "know" about penalties.
