## Decisions made

- **`ApiErrorDetail.timestamp` self-stamps via `Field(default_factory=...)`** — evaluated fresh per instance, not at import; `ApiError` doesn't set it.
- **`ApiError.__init__` builds the detail internally** — keeps the 9 future route call-sites clean (`ApiError(404, NOT_FOUND, "msg")`).
- **Only `status_code` + `detail` live on `ApiError`** — those are what FastAPI/`main.py` read; `code/message/details/path` live inside the detail.
- **`detail` typing: `cast(Any, ...)` at write + `cast(ApiErrorDetail, ...)` at read** — Starlette declares `HTTPException.detail: str`, so a class-level override is rejected. `cast()` is site-local; both the `__init__` assignment and the handler read need it. Verified green with a scratch script.
- **`path` backfilled in the handler, not per-route** — the handler already has `Request`; avoids plumbing `request.url.path` through 9 call-sites.
- **generic handler mutates the caught exception only as a terminal step** — the exception is about to be serialized and discarded, so mutating it there is contained, not a leak.
