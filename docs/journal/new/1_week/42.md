## What I learned today

- **Windows + psycopg async needs `WindowsSelectorEventLoopPolicy`** — ProactorEventLoop raises `InterfaceError`. Fixed in `tests/conftest.py` at module load. Still need to consider if this breaks non-Windows runners (it shouldn't — they already use SelectorEventLoop).
- **`SessionLocal` imported at module level** in `persist.py` and `approval_gate.py` — rebinding `db_session.SessionLocal` isn't enough; must rebind `persist_module.SessionLocal` and `approval_gate_module.SessionLocal` too. The fixture does this explicitly now.
- **`recommendations.id` has no auto-increment** — pre-inserted rows with ID 3 conflicted with persist node's auto-generated ID 3 in subsequent tests. Switched to ID 999999 for pre-inserted rows.
- **Resume on unknown thread does NOT raise "missing-checkpoint"** — LangGraph starts a fresh run, hits state validation (`InvalidStateError` because `manager_id` is None). The ghost bug from journal 41 is confirmed fixed: no silent re-run, just a validation error.
