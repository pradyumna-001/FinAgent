## Decisions made

- **Graph shape locked** — `editor → persist_recommendation → send_note → approval_gate → END`. Send and wait are split into two nodes so the send runs exactly once: on resume, LangGraph re-executes **only the interrupted node**, so a completed `send_note` node never re-fires. (Rejected: one node + Redis `note_sent` marker — external state, TTL can be outlived by the pause.)
- **`persist_recommendation` is its own node** (SRP) — DB insert does not live inside the send node. Failure modes stay separate, send node stays trivially unit-testable.
- **`interrupt()` semantics confirmed** (langgraph.types, v1.2.11): first call raises `GraphInterrupt`, graph pauses + checkpoints; resume via `Command(resume=decision)` + same `thread_id = pipeline_run_id`; on resume the node **re-executes from the top** and `interrupt()` returns the decision. Requires a checkpointer — `AsyncPostgresSaver` survives worker restarts, `InMemorySaver` (dev_graph) orphans the run.
- **RLS semantics** — `USING` filters existing rows (SELECT); `WITH CHECK` validates new rows (INSERT). Without `SET LOCAL app.manager_id`, `current_setting(..., true)` returns NULL → `WITH CHECK` FALSE → INSERT rejected loudly (42501), not succeed-invisibly.
- **Node session ownership** — graph nodes have no DI; node opens `SessionLocal` itself. `get_session`/`get_read_session` are async generators for FastAPI `Depends` only. `async with SessionLocal()` guarantees session close on both exit paths (normal + exception) → no connection leak → pool exhaustion protection. A node function containing `yield` becomes an async generator — body never runs when awaited (would TypeError at runtime).
- **mypy blind spot found** — code after `while True:` with no break is unreachable and **not type-checked**. Poller line 77's positional DataFlag survived because of this. Fixed with keyword args. Lesson: "mypy clean" ≠ correct.
