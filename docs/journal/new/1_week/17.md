6. **Debugging session — the AsyncMock `__aexit__` bug (chunk 7)**: `test_search_http_failure_returns_warning` failed with `UnboundLocalError` on `data` (line 77 of `tavily.py`). Root cause: the `_mock_client_raises` helper set `__aexit__.return_value = AsyncMock(return_value=None)` — but `AsyncMock(return_value=None)` is a truthy mock INSTANCE, not None. Per Python's `async with` semantics, a truthy `__aexit__` return SUPPRESSES the exception. The `ConnectError` was silently swallowed at the with-block level, execution continued after the `async with` to line 77 where `data` was never assigned → `UnboundLocalError`. Fix: removed the `__aexit__.return_value = ...` override entirely — `AsyncMock`'s default `__aexit__` returns falsy, let the exception propagate correctly. Lesson: when overriding a mock whose contract depends on falsy-vs-truthy (like `__aexit__` propagating exceptions), use literal `None` or `False`, not `AsyncMock(return_value=None)`. The latter is truthy. This was the FOURTH mock-invisible bug of the refactor (after `timenout` typo, `and`/`or` confusion, query-string omission).

## Decisions made

- **Service boundary = `app/services/tavily.py`.** Service module owns: TavilyError hierarchy, TavilyArticle/TavilyResult dataclasses, TavilyService class with construction-time key validation and the search() method. Imports `DataFlag`/`Severity` from `app/utils/flags.py` (codebase-side contract) — never duplicates `Severity` (duplicate-enum-class identity bug class).
- **Exception hierarchy convention:** domain-scoped like `PipelineError`, never speculative shared `ServiceError` base. The test for "does this class belong in utils/" is "does any consumer of this class NOT already know about its producer?" TavilyConfigError's consumers all already import `app.services.tavily` → co-located, not utils.
- **Raise vs. return across the boundary:**
  - `TavilyConfigError` — RAISED at construction (catch once per pipeline run). Reason: missing-key is unrecoverable, bail-and-return is the same regardless of agent, agent has no useful state mutation beyond "set empty and return."
  - `TavilyRequestError` (HTTP) — returned as `TavilyResult.error` (WARNING). Reason: agent must mutate state (flag + set empty + timestamp); return-based contract keeps state mutation local to the agent.
  - `TavilyParseError` (parse) — returned as `TavilyResult.error` (FATAL for null title/content). Same reason. Note: the `TavilyRequestError` and `TavilyParseError` classes are documentation-only in v1 — `search()` builds the DataFlag inline rather than instantiating them. Kept in the hierarchy for future retry-policy discrimination.
- **FATAL rule generalized from company.py policy:** service carries `any(a.title is None or a.content is None for a in articles)` = FATAL. Macro inherited the stricter policy (was: silent None with no flag — #61 Part 2 bug fixed by extraction rather than by in-place backport). Verified that the `any(α or β)` form is equivalent to `any(α) or any(β)` (distributive law of `any` over `or`).
- **Empty `{"results": []}` is valid:** NOT fatal, returns `TavilyResult(articles=[], error=None)`. Distinguishes "no matches" (Tavily honored the contract) from "schema broke" (null fields in returned articles). Operator not paged on slow news days.
- **Query string in FATAL message via `!r`:** operator sees exactly what Tavily searched for, can re-run manually. The query is universally available (passed as `search()` param); ticker is agent-specific (service doesn't know `company_ticker`). `!r` wraps in single quotes and escapes whitespace — operator sees doubled-spaces and hidden chars literally.
- **Construction per-call inside the node function** (Option B for placement): `try: tavily = TavilyService(api_key=settings.TAVILY_API_KEY); except TavilyConfigError: ...`. NOT module-level — module-level would import-time-crash when `TAVILY_API_KEY` is unset, breaking tests (which would re-introduce the `with patch("app.core.config.settings.TAVILY_API_KEY", "dummy"):` boilerplate we just eliminated), breaking CI (no `.env`), and breaking hot reload.
- **Tests mock at the TavilyService boundary** for agent tests (Option A — patches `app.agents.macro.TavilyService` and returns a `MagicMock` whose `.search` is an `AsyncMock` returning a `TavilyResult`). The service's own tests mock at the `httpx` boundary (Option B — exercises the real parse/validation/FATAL logic). Layered tests: outer layer (agent) is black-box, inner layer (service) is behavior-box.
- **Mock-fraud lessons:** (1) `timenout=...` kwarg typo invisible because mocks accept any kwarg. Real `httpx.AsyncClient(timeout=10.0)` construction would have caught it. (2) `all(... and ...)` vs `any(... or ...)` confusion: tests passed because mocked tests don't exercise real parse logic. Service-layer tests (chunk 7) catch it. (3) `AsyncMock(return_value=None)` is truthy — if set as `__aexit__.return_value`, silently suppresses exceptions. Fix: use literal `False` or remove the override entirely. (4) `DataFlag(sources="tavily")` typo in company.py catch path would have crashed silently. Caught by reading, not by tests.
- **`uv.lock` deliberately uncommitted** — existing standing decision (per `16.md`) to keep OpenAI/httpx dep changes separate from feature commits. Continued.
