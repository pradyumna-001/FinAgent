## Decisions made

- **Incremental migration with adapter** (ADR-038) — Zero-downtime migration of 75 call sites; `create_initial_state` deprecated but functional
- **LangGraph `Send` API for fan-out** — Dynamic, handles any portfolio size (1-50+ tickers); cleaner than static graph with 60+ nodes
- **Consolidate node in Python** — Deterministic portfolio risk, no LLM cost; extensible for future `PortfolioRiskAgent`
- **Standalone test runner** — Bypasses Windows testcontainer connection issues; uses existing PostgreSQL container directly

## Decisions worth flagging

- **Testcontainer issues on Windows** — Integration tests using `pg_container` fixture fail with connection resets; standalone runner works against existing container

- **`merge_dicts` reducer** — Shallow merge `{**left, **right}` works because parallel agents write different ticker keys
- **`portfolio_id` already existed** — No migration needed; was already in `MorningNote` model
