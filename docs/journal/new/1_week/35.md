## Decisions made

- **Failure SSE events** — convention check: `company.py:56` emits `agent_completed` even on failure; send.py mirrors it. Diff vs success visible to frontend only through flags. (Noted in follow-up as codebase-wide observation.)
- **Post-editor FATAL flags** — editor consumes flags before persist/send run, so those flags never reach the note. Interim: SSE + structural logging. Durable storage → follow-up filed.
- **Factory returns None, node decides severity** — library layer returns/raises; application layer assigns meaning. Poller wants INFO (dev/CI no-token auto-pass), send node wants FATAL (note undeliverable mid-graph).
- **ChannelError hierarchy deferred** — broad `except Exception` for now; typed hierarchy + retry discrimination → follow-up filed. Docstring in `base.py:23` still promises subclasses that don't exist.
- **Severity criterion corrected** — "can it be fixed?" is not severity. No-token in prod = silent non-delivery = FATAL. Fail-visible invariant.
