## Decisions made

- **Fan-out `Send` API injects `current_ticker`** — Agents read directly from state; no fallback needed (fail-fast via `KeyError` if fan-out contract violated)
- **EditorAgent single LLM call** — Simplifies cross-ticker consistency validation vs per-ticker concurrent calls; slight parallelism trade-off for large portfolios
- **Per-ticker confidence penalties** — Each ticker's sections penalized independently; warning messages include ticker name (`[Aviso]: PETR4 - company - ...`)
- **Missing ticker handling** — Placeholder `{}` recommendations + `[]` confidence_scores + DataFlag (fail-visible, not silent)
- **Editor JSON parsing robustified** — Catches `JSONDecodeError`/`TypeError`/`ValueError`; validates `parsed` is dict; validates nested dicts; validates `morning_note` is string

---

## Decisions worth flagging

- **Editor prompt now renders all tickers in one prompt** — Longer prompt but single LLM call; within token limits for typical portfolio sizes (5-10 tickers)
- **Missing tickers get empty dicts** — `send_node` checks `.get(ticker) is not None`, so empty dict `{}` would pass through; we intentionally DON'T add ticker to `recommendations` for missing tickers (key simply absent → `get()` returns None → treated as missing)
- **13 fixup commits squashed conceptually** — Iterative fixes (lint, mypy, test mocks) collapsed into coherent feature work via rebase+merge
