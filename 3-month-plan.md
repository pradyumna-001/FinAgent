# 3‑Month Plan – AI Engineer Roadmap

**Goal:** Become a production‑ready AI engineer and land a US‑based remote role within 12 weeks.  Deliver a polished **FinAgent** product, solid FastAPI & TypeScript expertise, and a demonstrable AI‑engineering knowledge base for the recruiter.

---

## 1. Overall Structure

| Week | Focus Area | Primary Deliverable |
|------|------------|--------------------|
| 1‑2  | Foundations – project setup, core FastAPI concepts, TypeScript basics | FinAgent repo initialized, FastAPI "Hello‑World" service, TypeScript tooling (tsc, eslint) |
| 3‑4  | FastAPI deep‑dive & API design | CRUD endpoints for portfolio data, authentication skeleton, automated tests |
| 5‑6  | TypeScript & Front‑end integration | Typed API clients, simple React/NextJS UI mock‑up, end‑to‑end tests |
| 7‑8  | AI‑Engineering curriculum integration | Complete **Phase 0‑3** of *ai‑engineering‑from‑scratch* (≈ 90 h) and build notebook demos linked to FinAgent |
| 9‑10 | FinAgent core features | Implement MacroAgent → EditorAgent pipeline, Celery workers, DB schema, basic UI for morning notes |
| 11‑12| Polish, performance & deployment | Load‑testing, CI/CD (GitHub Actions), Docker + AWS/ECS deployment, documentation, final demo video |

Each two‑week block includes:
- **Morning (1 h):** LeetCode practice + reading 2 research papers.
- **Morning (additional 30 min):** FastAPI/AI‑engineering study.
- **Afternoon (≈ 5 h):** FinAgent development + related learning tasks.
- **Evening (30 min):** Write a LinkedIn post summarising the day’s achievement.

---

## 2. Weekly Breakdown

### Week 1 – Project Bootstrapping
- Set up Git, CI (GitHub Actions lint/test), Docker dev environment.
- Create FastAPI skeleton (`app/main.py`) with a health endpoint.
- Initialise a TypeScript monorepo (`tsconfig.json`, `eslint`, `prettier`).
- Draft FinAgent architecture diagram & backlog in Notion.
- **LinkedIn:** "Starting my AI‑engineer journey with FastAPI & TypeScript. #AI #Backend"

### Week 2 – FastAPI Basics & Testing
- Implement GET/POST endpoints, Pydantic models, error handling.
- Write unit tests using `pytest` & `TestClient` (≥ 80 % coverage).
- Add Swagger UI customization & JWT auth stub.
- Begin *ai‑engineering‑from‑scratch* Phase 0 (tooling) – 4 h.
- **LinkedIn:** Share a short demo of a FastAPI CRUD service.

### Week 3 – TypeScript Fundamentals
- Study TypeScript typing, interfaces, generics (30 h from the curriculum).
- Build a typed HTTP client (`axios`‑like wrapper) for the FastAPI API.
- Write simple React component that consumes the client.
- FastAPI: add query parameters, pagination.
- **LinkedIn:** Explain why static typing matters for AI services.

### Week 4 – API Design & Security
- Design versioned routes (`/v1/…`), middleware for logging, CORS.
- Implement role‑based JWT auth, refresh tokens.
- Add OpenAPI tags, response models, and automated doc generation.
- **AI‑Eng:** Finish Phase 1 (Math Foundations) – 15 h.
- **LinkedIn:** Post about securing FastAPI endpoints.

### Week 5 – Async & Performance
- Convert blocking DB calls to async (`SQLModel` or `AsyncSQLAlchemy`).
- Benchmark with `locust`, configure Uvicorn workers (4 workers).
- Add Redis cache layer for cheap look‑ups.
- **AI‑Eng:** Phase 2 (ML Fundamentals) – 12 h.
- **LinkedIn:** Share a latency benchmark chart.

### Week 6 – Front‑end Integration
- Complete React UI: list of portfolio companies, refresh notes via SSE.
- Use TypeScript `useEffectEvent` / `useDeferredValue` for smooth updates.
- Write integration tests with `Playwright` (fastapi‑ui‑e2e).
- **AI‑Eng:** Phase 3 (Deep Learning Core) – 12 h.
- **LinkedIn:** Demo of real‑time UI with Server‑Sent Events.

### Week 7 – FinAgent Core – Macro & Company Agents
- Implement MacroAgent: fetch macro news, store in PostgreSQL+AGE.
- Implement CompanyAgent & QuantAgent (parallel execution via LangGraph).
- Write unit tests for each agent’s `run` method.
- **AI‑Eng:** Phase 4 (Computer Vision) – 10 h (focus on data pipelines).
- **LinkedIn:** Explain multi‑agent pipelines for financial analysis.

### Week 8 – FinAgent Core – Risk & Editor Agents
- Build RiskAgent (adversarial questioning) and EditorAgent (note synthesis).
- Add streaming endpoint `/pipeline/status` using SSE.
- End‑to‑end test: start pipeline, verify generated note structure.
- **AI‑Eng:** Phase 5 (NLP) – 10 h (focus on prompting & LLM wrappers).
- **LinkedIn:** Show a sample morning note generated by FinAgent.

### Week 9 – Data Layer & Observability
- Design PostgreSQL schema, pgvector + HNSW index for historical notes.
- Integrate LangSmith tracing, CloudWatch metrics, basic Grafana dashboards.
- Write migration scripts (Alembic) and test roll‑backs.
- **AI‑Eng:** Phase 6 (Reinforcement Learning) – 8 h (optional preview).
- **LinkedIn:** Post on observability for AI pipelines.

### Week 10 – Testing, CI & Security Hardening
- Full test suite: unit, integration, e2e, load‑testing.
- GitHub Actions workflow: lint → test → Docker build → security scan.
- Perform static code analysis (`bandit`, `npm audit`).
- Conduct a security review (input validation, rate limiting).
- **LinkedIn:** Share CI pipeline screenshot and lessons learned.

### Week 11 – Deployment & Scaling
- Write Dockerfile, Docker‑Compose for local dev, and production compose.
- Deploy to AWS ECS (or Render) with auto‑scaling, health checks.
- Set up zero‑downtime blue‑green deployment scripts.
- Verify end‑to‑end flow in the cloud environment.
- **LinkedIn:** Announce FinAgent public demo URL.

### Week 12 – Polish, Documentation & Recruiter Deliverables
- Finalize README, API spec (OpenAPI 3.1), architecture diagram.
- Record a 5‑minute demo video (+ subtitles) and upload to YouTube.
- Prepare a one‑page “Engineering Portfolio” PDF (project overview, metrics, links).
- Send recruiter the PDF, the GitHub repo link, and the demo video.
- **LinkedIn:** Publish a “3‑month journey recap” post, tag the recruiter (if appropriate).
